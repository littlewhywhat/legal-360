# Rooms — my list

Jordan's phone. Home is a personal list across rooms, not a room picker.

A room is a team space: one context, one artifact set, one stakeholder group. Missions live inside it. A playbook is the checkpoint chain on a single mission.

## List

Filters: QQ, DQ, In play.

- QQ — answer now. The agent stays on that mission.
- DQ — a review slot. No push. The agent returns to the room pool.
- In play — Jordan is on the mission and is not blocking it.

Each row names its room. Helios MSA, Acme DPA, and Northwind NDA are all on the same list.

## Create

New mission picks a room, then a playbook. The room already has the people and the shared artifacts. Start pulls an agent from that room's pool and drops the first artifact.
