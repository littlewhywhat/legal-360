# Room → Mission → Playbook

One room, two missions. Walk Pricing section to Done. Hero contrast stays on a UX slot so the agent returns to the pool.

1. Room. Pool idle. Open Pricing section.
2. QQ to PO, private thread. Answer Annual.
3. Decision artifact lands on the mission.
4. Agent writes the spec, hits Design, releases. DQ is queued, not pushed.
5. Pool evaluates Hero contrast and comes back. The UX slot still holds that mission.
6. PO inserts Legal copy before Accept.
7. UX attaches design in their own thread. PO's thread is gone from this side.
8. Agent writes the diff, verification, and legal copy between gates.
9. QQ to PO. Accept → Done, or Garbage. Artifacts stay either way.
